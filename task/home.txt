Buatkan homepage untuk website penerbit buku bernama "Interlude" menggunakan Laravel 13 dan Bootstrap 5 (versi terbaru).

Konteks & Identitas Brand:

Nama penerbit: Interlude
Kesan yang ingin ditampilkan: elegan, literary, hangat, dan modern — cocok untuk penerbit buku (bukan e-commerce umum)
Palet warna: gunakan warna netral/earthy (krem, coklat tua, off-white) dengan satu warna aksen (misalnya maroon atau navy) — sesuaikan jika saya sudah punya brand guideline
Font: kombinasi serif untuk judul (kesan literary) dan sans-serif untuk body text

Struktur Teknis:

Gunakan Laravel Blade dengan layout utama (layouts/app.blade.php) dan komponen terpisah untuk tiap section (components/navbar.blade.php, components/hero.blade.php, dll)
Gunakan Bootstrap 5 terbaru via CDN atau npm (jelaskan cara install via Laravel Mix/Vite)
Buat Controller HomeController dengan method index() yang mengirim data dummy/eloquent untuk 3 kategori buku
Buat Model Book dengan field relevan: title, author, cover_image, price, category, is_new, is_popular, is_bestseller, published_at, sold_count, dll
Sertakan contoh migration dan seeder untuk data dummy buku

Struktur Halaman Homepage:

Navbar
Logo "Interlude" di kiri
Menu: Beranda, Blog, Galeri, Tentang Kami, Kontak
Search bar untuk mencari buku
Icon keranjang/wishlist (opsional) dan tombol Login/Register
Responsive (collapse jadi hamburger menu di mobile) menggunakan Bootstrap Navbar component
Hero Section
Headline besar yang menonjolkan tagline penerbit (misal: "Setiap Buku, Sebuah Jeda untuk Berpikir")
Subheadline singkat tentang Interlude
CTA button ("Jelajahi Koleksi")
Gambar/ilustrasi buku atau banner buku unggulan
Gunakan Bootstrap grid & carousel jika ingin menampilkan beberapa buku unggulan bergantian
Section "10 Buku Terbaru"
Judul section + link "Lihat Semua"
Grid/carousel card buku (cover, judul, penulis, harga, badge "Baru")
Ambil data dari Book::where('is_new', true)->latest()->take(10)->get()
Section "10 Buku Populer"
Sama seperti di atas, tapi berdasarkan is_popular atau jumlah view/wishlist
Bisa tampilkan badge "Populer" dan indikator (misal jumlah pembaca)
Section "10 Buku Paling Laris"
Berdasarkan sold_count terbanyak, urutkan descending
Tampilkan badge "Best Seller" dan mungkin ranking (#1, #2, dst)
Untuk ketiga section buku, gunakan card component yang reusable (components/book-card.blade.php) agar konsisten, dengan hover effect (misalnya cover sedikit zoom saat hover) menggunakan CSS custom + Bootstrap.
Footer
Logo & deskripsi singkat Interlude
Kolom menu: Tentang Kami, Katalog, Kebijakan Privasi, Syarat & Ketentuan
Kolom kontak: alamat, email, nomor telepon
Kolom sosial media (icon Instagram, Twitter/X, Facebook)
Newsletter subscription form
Copyright bar di paling bawah

Requirement Tambahan:

Fully responsive (mobile, tablet, desktop)
Gunakan lazy loading untuk gambar cover buku
Sertakan komentar kode yang jelas agar mudah dikembangkan
Sertakan file CSS custom terpisah (resources/css/interlude.css) untuk override/tambahan style di luar Bootstrap default
Jelaskan struktur folder file yang dihasilkan
