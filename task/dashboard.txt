Buatkan halaman **Dashboard Admin** menggunakan **PHP + Bootstrap 5** yang terintegrasi dengan sistem authentication/login yang sudah ada.

Gunakan struktur dan praktik yang sesuai dengan framework yang digunakan, yaitu **CodeIgniter/Laravel**. Jangan membuat sistem login baru apabila authentication sudah tersedia. Gunakan session/authentication bawaan framework.

## 1. Alur Authentication

Setelah user berhasil login:

```text
Login
  ↓
Validasi username/email & password
  ↓
Login berhasil
  ↓
Simpan session/auth user
  ↓
Redirect ke /dashboard
  ↓
Dashboard
```

Dashboard harus hanya dapat diakses oleh user yang sudah login.

Jika user belum login dan mencoba mengakses:

```text
/dashboard
```

maka user harus diarahkan kembali ke halaman login.

Gunakan authentication middleware/filter bawaan framework.

## 2. Informasi User

Dashboard harus mengambil informasi user yang sedang login dari session/authentication, bukan menggunakan data hardcode.

Tampilkan:

* Nama user
* Email user
* Role user
* Avatar/default profile image

Contoh:

```text
Welcome, John Doe
john@example.com
Administrator
```

Jika menggunakan Laravel, gunakan authentication seperti:

```php
Auth::user()
```

Jika menggunakan CodeIgniter 4, gunakan session/authentication yang sesuai dengan konfigurasi project.

## 11. Struktur Code

Jangan membuat seluruh aplikasi dalam satu file.

Sesuaikan struktur dengan framework.

### Jika CodeIgniter 4

Gunakan struktur seperti:

```text
app/
├── Controllers/
│   └── Dashboard.php
│
├── Views/
│   ├── layouts/
│   │   ├── header.php
│   │   ├── sidebar.php
│   │   └── footer.php
│   │
│   └── dashboard/
│       └── index.php
│
├── Models/
│   └── UserModel.php
│
└── Config/
    └── Routes.php
```

### Jika Laravel

Gunakan struktur seperti:

```text
app/
├── Http/
│   └── Controllers/
│       └── DashboardController.php
│
├── Models/
│   └── User.php
│
resources/
└── views/
    ├── layouts/
    │   └── app.blade.php
    │
    ├── components/
    │   ├── sidebar.blade.php
    │   └── navbar.blade.php
    │
    └── dashboard/
        └── index.blade.php
```

Sesuaikan implementasi dengan framework yang digunakan.

## 12. Route

Buat route:

```text
GET /dashboard
```

yang mengarah ke Dashboard.

Dashboard harus dilindungi authentication.

Contoh Laravel:

```php
Route::middleware(['auth'])->group(function () {
    Route::get('/dashboard', [DashboardController::class, 'index'])
        ->name('dashboard');
});
```

Untuk CodeIgniter, gunakan Filter/Middleware authentication yang sesuai.

## 15. Security

Perhatikan aspek keamanan:

* Dashboard tidak boleh dapat diakses tanpa login.
* Jangan menggunakan password dalam bentuk plaintext.
* Logout harus benar-benar menghapus authentication/session.
* Gunakan CSRF protection bawaan framework.
* Validasi seluruh input.
* Jangan menampilkan informasi sensitif user.
* Jangan melakukan query database langsung dari View.
